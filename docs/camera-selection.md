# 測定カメラの選択

設定の「アカウント」の直前に「測定に使うカメラ」を表示する。ログイン・開発者権限は不要。

- 選択値は `piiin.camera.device.v1` に保存する端末設定。アカウントの切替とは独立し、サーバーには送らない。Webのブラウザー／オリジンとデスクトップアプリはそれぞれ別に設定する。
- 通常測定・姿勢登録プレビュー・`/dev/model`・開発用タイムラプスプレビューは同じ取得処理を使う。タイムラプス本体は測定中のストリームを使う。
- 次のカメラ起動時に反映する。起動済みの数式画面は開き直す。測定中のカメラや登録済みの基準を途中で切り替えない。
- 設定を開くだけではカメラを起動しない。デバイス名の取得に権限が必要な場合だけ「カメラ一覧を更新」で一時的に取得し、一覧取得後・エラー・画面終了時に停止する。
- 未接続の選択値は保持する。別カメラへの自動フォールバックをせず、再選択を案内する。「自動」を選ぶと標準カメラを使う。

## 検証（2026-11-27）

- `camera-settings.test.tsx`: 選択と永続化、実測定フックへの適用、解像度再試行、権限拒否、未接続、一覧取得失敗、遅延取得後の解放、保存失敗、翻訳。
- `model-lab.test.tsx`: 保存済みカメラを数式画面でも指定することを追加検証。
- ローカルQAは実際のWorkApp・設定コンポーネントを使用し、カメラと未ログインAPIだけを模擬した。実カメラの映像は取得していない。
- 1512×982（日本語）、1024×640（英語）、390×844（韓国語）でアカウント直前の配置とスクロール到達を確認。ページ・ダイアログの横方向オーバーフローはいずれも0px。入力欄は高さ47px、更新ボタンは44〜47px、要素間隔12px、アカウントまで28px。キーボードフォーカスは3pxの輪郭線。
- 長いデバイス名は狭い画面で選択欄内に省略表示する。実機のUSBカメラ切替、macOS/Windowsの権限ダイアログ・ドライバー別動作は未検証。
