# 홈·상세 카드·측정 효과음 검증

검증일: 2026-10-27 (JST). 웹 PiiiN과 Tauri posture-app에 동일한 UI 변경을 적용했다. 기존 작업 브랜치 `feat/story-home-refresh`의 타이머·저장소 변경을 보존했다. 아래는 구현 검증 시점의 기록이다. 후속 요청에 따라 `fix/home-timer-sound-fidelity` 브랜치로 게시한다.

## 범위와 기준

- 홈: Figma `4006:1440` / 헤더 `4006:1441`, 사용자가 제공한 홈 CSS와 기준 스크린샷.
- 상세 카드: 홈의 `クリック時` 프레임 `4057:5766`을 직접 확인하고, 제공된 721×409 획득 카드 CSS도 별도로 비교했다. 홈 상세 기준은 911.39×517이다.
- 측정·휴식·일시정지: 세 화면을 각각 브라우저에서 확인하고 사용자가 제공한 각 CSS와 비교했다. 일시정지 기준 노드는 `4057:5125`이다.
- Figma MCP 할당량 제한 이후에는 Figma 브라우저와 제공된 CSS를 사용했다.
- 모바일, 캐릭터 카탈로그·이미지 원본, 저장/통신 계약은 변경하지 않았다. 데스크톱에 있던 측정 화면의 별도 안내 문구도 유지했다.

## 구현

- 홈의 그라데이션 높이, 버튼 간격, 컬렉션 카드 위치·별·태그·이미지 크기를 맞췄다. 좁은 화면에서는 카드 내용을 자연스럽게 줄바꿈한다.
- 오토아나고의 홈 이미지가 기존 220px 정도로 확대되던 부분을 Figma의 188px로 수정했다. 17종 각각의 이미지와 보이는 영역을 비교했다.
- 홈 캐릭터의 기존 숨 쉬기 keyframes, 4초 ease-in-out 반복과 0.9초 지연, 카드/이미지 hover 이동 값은 원본과 동일하다. 실제 실행에서 숨 쉬기 transform 변화도 확인했다.
- 상세의 `集中した時間` / `ピーン率` 라벨을 숫자 열 위에 중앙 정렬하고 단위를 별도 열에 배치했다. 외부 원형 닫기·공유·저장 버튼과 기존 광택·hover 효과를 복구했다. PNG 내보내기 시 버튼과 효과는 제외된다.
- 상세 모달을 닫으면 원래 카드 버튼으로 키보드 포커스가 돌아간다. 그래프의 실제 기록과 끊김·상세 표시 동작을 유지했다.
- 효과음은 집중에서 휴식으로 전환할 때 한 번만 재생한다. 자세 회복, 휴식→집중, 재개, 최종 완료에서는 재생하지 않는다.
- `カメラで姿勢をチェック中`와 `サウンドを追加・試聴` 링크를 측정 화면에서 제거했다. 추적 실패·휴식·일시정지 안내는 유지했다.
- 효과음 메뉴를 흰색 둥근 메뉴, 선택 체크, hover, 키보드 포커스 스타일로 교체했다. 아래 공간이 부족하면 위로 열린다. 기존 음량·음소거·선택 저장은 유지한다.

## 실행 검증

- 웹과 데스크톱 각각 `bun run build` 성공. 기존 Lottie eval 및 chunk 크기 경고는 남아 있다.
- 웹과 데스크톱 각각 `bun run test:work`: **19 passed / 0 failed, 78 assertions**. 효과음 전환 조건 2개 회귀 테스트를 추가했다.
- 데스크톱 `cargo check --manifest-path src-tauri/Cargo.toml` 성공. 기존 unused/dead-code 경고 32개가 남아 있다.
- 홈 13개 해상도: 1920×1080, 1512×982, 1280×720, 1200×752, 1199×752, 1024×768, 851×600, 850×600, 720×512, 601×600, 600×600, 390×844, 320×640. 각 화면의 17종 카드 이름·별·태그와 페이지에서 가로 넘침이 없고 헤더 요소가 겹치지 않음을 확인했다.
- 상세 7개 해상도: 1512×982, 1200×752, 850×600, 720×512, 540×600, 390×844, 320×640. 가로 잘림 없이 작은 화면에서 세로 스크롤로 접근했다. 그래프 키보드 상세 표시와 Escape 닫기/포커스 복귀를 실행했다.
- 효과음: 측정·휴식·일시정지 각 6개 해상도(1512×982, 1200×752, 850×600, 720×512, 390×844, 320×640), 총 18조합. 메뉴가 화면 안에 있고 삭제 요청 문구가 없음을 확인했다. 방향키, Home/End, Enter, Escape, Tab, 바깥 클릭을 확인했다.
- 실제 macOS Tauri 앱에서 1200×752 및 720×512 창으로 홈·상세·효과음 메뉴를 확인했다. 작은 창에서 효과음 메뉴가 위쪽으로 열리며 End→Enter로 5번 선택과 닫기가 동작했다.
- 실제 저장 버튼으로 1822×1062 PNG를 내려받아 카드만 저장되고 외부 버튼·효과가 빠지는 것을 확인했다.
- `git diff --check` 통과. 두 저장소의 공통 UI 파일 일치를 검사했다.

## 남은 차이와 미검증 범위

- 실제 카탈로그 설명이 시안 예시보다 길어 웹 오토아나고 상세 높이는 530.85px이다(시안 517px). 문구를 줄이거나 자르지 않고 카드 높이가 늘어나도록 했다. 번호·날짜·그래프 모양도 실제 데이터에 따른다.
- 효과음 버튼 높이는 시안 41.36px 대신 터치 영역을 위해 44px이다. 작은 화면의 줄바꿈·열 수는 반응형 조정이다.
- 이전 50점 기준선 의미와 그래프 데이터는 변경하지 않았다. 시안의 샘플 곡선을 실제 측정값처럼 복제하지 않았다.
- 실제 카메라로 자세를 바꾸는 통합 시나리오와 스피커 청취는 이번에 실행하지 않았다. 소리 발생 조건은 자동 테스트로 검증했고 음원 재생 서비스는 변경하지 않았다.
- Windows 실행, OS Reduce Motion 설정을 켠 실제 실행은 미검증이다. reduce-motion CSS 유지 여부는 코드로 확인했다.
- 저장 PNG 검증 이후 최종 변경은 홈/측정 CSS와 상세 문구 줄바꿈이었다. 최종 빌드는 다시 실행했다.
