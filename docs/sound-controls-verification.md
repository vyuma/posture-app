# 測定・休憩・一時停止のサウンド欄修正

確認日: 2026-10-29

## 原因と変更

1920×1080で「効果音」は約14pxに拡大される一方、ラベル幅が39px固定だったため、2文字＋1文字に折り返されていた。また、ドロップダウンの `height:100%` の親の高さが確定しておらず、基準解像度でも最小値28pxに縮んでいた。

- ラベル列を `max(3em, 39×画面倍率)` とし、改行を禁止。音量・効果音の2行を共通の2列グリッドで整列。
- 外枠、行間、内側余白、スライダー、ドロップダウンの寸法を `sound-select.css` に集約。重複した測定・レスポンシブCSSの上書きを除去。
- ドロップダウンの親と行の高さを確定し、基準では41.36px、小さい横画面では28px以上、狭い縦画面・タッチ端末では44pxを確保。
- 矢印をアウトラインの山形からFigmaと同じ塗りの逆三角形（11.4×6.23）へ変更。
- 同じコンポーネントを使う測定・休憩・一時停止に適用。アニメーション、音の再生条件、選択肢、設定の保存は変更なし。

WebとDesktopの変更ファイルは `SoundSelect.tsx` / `sound-select.css` / `measurement-layout.css` / `responsive-layout.css` の4つ。最終内容の一致を確認。モバイル・API・保存形式・キャラクター契約への変更なし。
