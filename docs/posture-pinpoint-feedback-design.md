# 부위별 안내와 측정 종료 코멘트

2026-11-26 설계 및 로컬 구현. 웹·데스크톱 공통 코드에 아래 변경을 반영했다. 서버 수집 계약과 운영 배포는 변경하지 않았다. 이전 말풍선 구현은 [기존 설계](posture-feedback-design.md)를 참조한다. 아래 표시 시점과 선택 정책은 이번 변경의 기준이다.

## 변경 전 확인한 구현

- `posture/engine.pose.metrics.ts`의 `computeHeadForwardAngle3D`는 귀 중심−어깨 중심 벡터와 수직축 사이의 YZ 평면 각도를 계산한다. 골반은 필요하지 않다. 현재 각도는 절댓값이므로 앞/뒤 방향을 보존하는 관측값이 추가로 필요하다.
- `posture/feedback.ts`의 기존 `headForward` 근거는 골반을 요구한다. 점수용 각도를 계산할 수 있는 것과 구체 안내를 할 수 있는 것은 현재 서로 다른 조건이다.
- 기존 피드백 이유는 얼굴 접근·머리 전방 이동·머리 기울기·몸통 기울기 네 가지다. 현재 점수에 쓰는 모든 특징에 방향별 안내가 붙어 있지는 않다.
- `work/postureReading.ts`의 `petPosture`와 `WorkApp.tsx`가 펫의 나쁨 상태를 결정한다. `posture/feedbackSpeech.ts`는 별도로 이유의 1,200ms 지속과 이유 전환을 계산하며, 이유 선택에 전체 나쁨 상태가 항상 필요한 구조는 아니다.
- `work/model.ts`의 일반 세션 표본에는 점수·편차·좋음/나쁨/인식불가가 있지만 부위별 원인·방향·지속 시간은 없다. 녹화의 말풍선 이벤트만으로 전체 세션의 원인을 집계할 수 없다.
- `ResultCard.tsx`는 현재 캐릭터의 고정 이야기를 표시한다. 측정 근거에 따른 종료 코멘트는 별도 연결이 필요하다.

## 확정한 표시 정책

1. 기존 나쁨 판정으로 펫 애니메이션이 바뀌기 시작하는 시점에 안내도 표시한다. 안내만을 위한 추가 대기시간을 두지 않는다. 애니메이션 종료를 기다리지 않으며 기존 모션·점수 임계값은 이 작업에서 바꾸지 않는다.
2. 나쁨 판정 전에도 이유 후보를 관측할 수 있지만 지적 문구는 표시하지 않는다. 애니메이션과 안내는 동일한 최신 관측·표시 상태를 사용한다.
3. 동시에 여러 원인이 있으면 현재 근거가 유효한 후보 중 정규화한 기준 초과 정도가 가장 큰 한 가지를 선택한다. 서로 다른 단위의 원시 각도·비율을 직접 비교하지 않는다.
4. 표시한 원인은 해결되거나 근거를 잃을 때까지 유지한다. 작은 순위 변화로 문구를 교체하지 않는다. 해결된 뒤에도 전체 나쁨 상태이고 다른 원인이 유효하면 남은 원인 중 하나를 안내한다. 이미 해결된 과거 원인은 대기열처럼 뒤늦게 표시하지 않는다.
5. 나쁨인데 특정 부위를 뒷받침할 수 없으면 일반 안내를 사용한다. 인식불가 때문에 펫이 나쁨인 경우에는 자세 원인을 지어내지 않고 인식불가 안내를 사용한다. 짧은 추적 유예는 기존 표시 정책을 따르고, 오래된 관측으로 새 원인이나 회복을 만들지 않는다.
6. 전체 좋음으로 회복하면 부위 지적을 끝내고 기존 회복 안내 정책을 따른다. 휴식·일시정지·기준 재등록·카메라 변경·세션 전환에서는 이전 원인 상태를 정리한다.
7. 여러 원인의 관측은 동시에 기록한다. 한 가지 문구만 보이는 동안에도 나머지 원인의 유효 지속 시간을 누락하지 않는다.

## 현재 관측값을 활용할 범위

모든 측정 특징을 근거로 활용하되, 같은 현상을 나타내는 특징은 합쳐서 안내한다. 아래 항목을 구현했다. 실카메라 정확도가 검증된 목록은 아니다. 방향은 사용자의 신체 기준으로 정하고 미러 화면에서도 일관되게 유지한다.

| 안내 대상 | 사용할 관측 | 구분해야 하는 경우 |
| --- | --- | --- |
| 머리의 전방 이동 | 귀 중심−어깨 중심의 방향과 각도, 가능한 경우 몸통 축 | 골반 없는 상반신 구도도 포함. 몸 전체 전진·회전과 혼동하지 않기 |
| 머리의 좌우 기울기 | 귀선·눈선의 부호 있는 각도 변화 | 좌우 회전·가림과 구분 |
| 머리의 좌우 치우침 | 어깨 중심에 대한 머리/코 위치 | 기울기와 중복 안내하지 않기 |
| 고개의 숙임·들림 | 코−귀 중심 방향, 목 각도와 등록값 변화 | 각도 절댓값만으로 방향을 단정하지 않기 |
| 어깨의 좌우 높이 변화 | 어깨선 높이 차이, 머리 기울기, 귀−어깨 거리 | 귀−어깨 거리만으로 어느 어깨가 올라갔다고 단정하지 않기 |
| 몸통의 좌우 기울기 | 실제 어깨 중심−골반 중심 축 | 골반 미검출 때 고정 수직축 대체값을 몸통 관측으로 쓰지 않기 |
| 얼굴 접근 | 얼굴 크기와 어깨 크기의 상대 변화 | 줌·카메라 이동·몸 전체 접근과 구분 |
| 고개의 좌우 회전 | 코·귀 위치와 부호 있는 회전 근거 | 시선·집중 상태로 표현하지 않기 |

화면 문구는 `頭が前に出てるよ！`, `頭が右に傾いてるよ！`처럼 짧은 관측 안내로 한다. 거북목·스트레이트넥 같은 상태의 진단을 문구로 단정하지 않는다. 카메라 구도·가시성이 부족한 항목은 판단을 보류한다.

## 종료 코멘트와 기록

- 이번 세션에서 가장 두드러진 패턴과 회복 또는 다음 행동을 짧은 두 문장으로 전한다. 각 문장은 명시적인 규칙과 관측 근거로 선택한다.
- 예: 해당 근거가 있을 때 `今日は頭が前に出る時間が多かったね。後半は登録した姿勢に戻せていたよ。`처럼 쓴다. 피로·집중 단절·의학적 개선을 추정하지 않는다.
- 원인별 유효 관측 시간, 원인이 지속된 시간, 방향, 회복 구간을 집계한다. 인식불가·휴식·일시정지는 원인 시간이나 회복으로 세지 않는다. 동시 원인이 있으므로 원인별 시간을 더해 전체 나쁨 시간이라고 하지 않는다.
- 기준 구간·피드백 판정 버전을 구분한다. 전반/후반의 관측량이나 기준이 비교 불가능하면 개선 문구를 만들지 않는다. 자료가 부족하면 측정 가능한 범위의 일반 코멘트를 표시한다.
- `いつもより`는 비교 가능한 과거 기록이 충분한 경우에만 사용한다. 이번 세션만으로는 쓰지 않는다. 구체 비교 조건과 시간 임계값은 구현 시 검증 사례에 따라 확정한다.
- 일반 로컬 세션에 녹화 여부와 독립적인 원인 요약을 보존해야 한다. 기존 기록에 없는 원인을 사후 추정해 채우지 않는다. 기존 세션을 계속 열 수 있도록 새 항목은 하위 호환을 유지한다.
- 원본 랜드마크의 서버 전송은 이번 합의에 포함하지 않는다. 새 요약의 서버 전송 여부도 별도 결정이며, 전송 시 허용 목록·서버 검증·참여 안내를 함께 바꾼다.

현재까지 골반 없이 전후 반대 방향의 합성 입력에서 기존 각도가 모두 약 18.43도로 나오고, 기존 피드백의 forward 값은 null인 것을 확인했다. 이는 코드 경로 검증이며 실제 카메라의 방향 판별 정확도 검증은 아니다.


## 구현한 임계값과 해석

기본 점수 판정은 `POSTURE_SPEC`를 그대로 사용한다. 기준 자세와의 차이를 정규화한 점수가 1.6 이상인 후보가 1,200ms 지속되면 나쁨, 회복은 1.2/350ms 기준이다. 추적 품질·랜드마크 누락·머리 회전에 대한 기존 별도 조건도 유지한다. 부위 안내의 강도 1은 각 부위 기준에 도달했다는 뜻이며, 총점 1과 같은 단위가 아니다.

| 부위 근거 | 변화량의 최소 기준 | 이번 작업 |
| --- | --- | --- |
| 머리 좌우 기울기 | 귀선·눈선 각도 12° | 기존 유지, 방향 추가 |
| 몸통 좌우 기울기 | 어깨−골반 축 10° | 기존 유지, 골반 필요 |
| 머리 전방 이동 | 어깨 너비 대비 0.18 | 기존 유지, 골반 없는 경로 추가 |
| 얼굴 접근 | 귀·눈 크기 18%, 어깨 대비 상대 증가 12% | 기존 유지 |
| 머리 좌우 치우침 | 어깨 너비 대비 0.12 | 새 안내의 초기 기준 |
| 고개 숙임·들림 | 코−귀 중심 방향 12° | 새 안내의 초기 기준, 3D 필요 |
| 어깨 좌우 높이 변화 | 어깨선 8° | 새 안내의 초기 기준 |
| 고개 좌우 회전 | 코−귀 중심 편차/귀 너비 0.22 및 등록값 대비 0.12 | 기존 정면 판별 경계 활용 |

각 기준은 등록 시 흔들림(MAD)의 5배가 더 크면 그 값을 사용한다. 얼굴 접근의 상대 증가 조건 등 기존 보조 조건은 그대로 유지한다. 해소 판정은 강도 0.65 미만이 350ms 지속되는 기존 방식을 유지한다. 말풍선을 시작하기 위한 별도 1,200ms 대기는 제거했다.

골반 없는 전방 이동은 귀−어깨의 앞쪽 변위와 머리 숙임 각도를 보정한 변위가 모두 증가해야 한다. 몸 전체를 고정된 형태로 기울인 합성 입력은 구체적인 전방 이동 안내를 만들지 않는다. 관측이 충분하지 않으면 일반 안내를 사용한다. 이는 실카메라 정확도 보장이 아니다.

로컬 세션에는 `feedbackVersion: 2`, 약 1초 간격 표본에는 관측 시각·정규화한 근거·방향을 선택 필드로 기록한다. 원본 랜드마크는 저장하지 않는다. 서버 업로드는 기존 허용 목록 그대로이므로 새 필드는 전송하지 않는다.

종료 코멘트는 같은 기준·구간·버전의 인접한 유효 표본만 사용한다. 1.5초를 넘는 공백·중복 관측은 제외한다. 최소 10초 및 집중 시간의 50% 이상을 관측해야 부위 코멘트를 만들며, 원인별 최소 3초 및 그 원인의 관측 시간 대비 10%를 적용한다. 회복 문구는 관측 가능한 연속 나쁨 3초 후 연속 좋음 3초를 확인한 경우만 사용한다. 좋은 자세 칭찬은 전체 집중 시간의 80% 이상이 근거로 확인된 경우에만 사용한다. 과거 세션 간 비교 문구는 이번 구현에 넣지 않는다.


## 이번 변경의 검증 결과

- 관련 Bun 테스트 115개 통과: 부위 방향·미러 좌우, 골반 없는 전후 이동, 몸 전체 기울임 구분, 나쁨 전환 시 즉시 안내, 원인 교체, 중복/공백/기준 변경, 체크포인트·중단 복구, 서버 전송 제외, 기존 위젯·타임랩스 동작.
