# ウィンドウサイズに応じた表示（2026-10-29）

## 変更範囲と方針

PiiiN Web と posture-app の共通 UI を更新。新しい `responsive-layout.css` は 1512×982 を基準に `min(幅/1512, 高さ/982)` から寸法を計算する。全体への CSS zoom / transform、毎フレームの JavaScript、別の ResizeObserver は追加していない。

- 横長のタイマー・姿勢測定・休憩・一時停止・登録・結果・タイムラプスは、幅だけでなく高さからもパネル、カメラ、余白、見出しを調整する。
- 主要操作は小窓でも高さ44pxを下限にし、補助ラベルにも最小文字サイズを設定。極端に低い窓では操作・文字を潰さず縦スクロールにする。
- 縦長の測定画面はカメラと操作部を縦に配置。ホームはスクロールする文書として扱い、83/1512の左右余白とカードの縦横比、列数の切り替えを維持。広いホームのヘッダーは幅に合わせて寸法を調整する。
- キャラクター選択は左右パネルの高さを揃え、リスト内部のスクロールと確定ボタンを維持する。
- 実アプリの `work-flow` と各画面の最小高さをviewportに合わせる。背景は全域を覆い、内容の下に無関係な灰色が出ないようにする。タイムラプス中の hidden は維持。
- 狭い画面の姿勢ガイドは同じ画像の左右を縦に配置。650px固定画像の横スクロールと途中切れを除去。説明文は変更せず、補助画像はアクセシビリティツリーから隠す。
- 同じflowラッパーを表示検証画面でも使用。Web/desktop の WorkApp や TimelapsePreview はプラットフォーム固有コードを維持し、CSS import のみ個別に追加した。

既存のアニメーション、キーフレーム、再生時間、タイマー・姿勢計測、保存形式、動画書き出し、カタログ、通信契約は変更していない。vibe-app は変更対象外。React の変更はflowラッパー、CSS import、静的なガイド画像のみで、新しい副作用や描画ループはない。
