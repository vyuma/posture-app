# ホームの操作と日本語・韓国語・英語対応

## 対象と境界

2026-11-26。統合リポジトリのWeb・macOS・Windows共通UI。ホームのLanguageとピンアナゴ変更、ログイン、同意・設問、設定、測定案内、部位別フィードバック、結果、コレクション、タイムラプス、主要エラーを日本語・韓国語・英語で表示する。iPhoneの独立アプリは対象外。

`src/features/i18n/messages.json`に711件の日本語キーと韓国語・英語訳を保持する。`t`は表示時に翻訳し、既存のキャラクターID・カタログ・測定記録・フィードバックコードを翻訳済み文字列で置換しない。言語は端末の`piiin-display-language`に保存し、初期値は日本語。別ウィンドウの変更も反映する。保存失敗時は前の言語を保ち、エラーを表示する。

認証ブラウザーへの遷移では許可した`ja/ko/en`だけを引き継ぐ。既存の`/api/profile/language`で分析プロフィールの言語を同期するが、回答日時・保持期限・所有者ID・同意状態は変えない。言語だけでデータ送信を開始しない。

原本画像に日本語が焼き込まれた姿勢ガイドは、元の図を保持し対応ラベルを重ねる。オンボーディングのロゴも既存画像を使い、非日本語時のキャッチコピーだけテキスト表示する。既存のアニメーション・タイミング・イージングは維持。Macウィジェットの同一発話IDで言語が変わっても発話開始時刻をリセットしない。
