# ADR 0006: 認証と任意の分析プロフィールを分離する

日付: 2026-11-10。状態: 実装中、外部メール・実機検証後に公開。

## 決定

メール認証・パスワード再設定は既存のBetter Auth/D1で扱い、Resendを送信に限定する。無料プランを維持し、Workerでも日100/月3000通を保守的に予約する。送信失敗を成功として返さない。認証メール送信先と認証データは分析用プロフィールから分ける。SSO専用アカウントへのパスワード再設定メールは発行しない。メールの一致だけではアカウントを統合しない。

既存user.idと端末の所有権を保持し、analysis_profilesに安定したUUIDを追加する。成人確認と新しい同意版をサーバーの送信条件とする。任意の出生時の性別・満年齢・言語は応答履歴に保存し、回答時点とuser/google_prefillの出典を残す。Google genderを出生時の性別の確定情報として移行しない。旧profile_snapshotsは旧形式のまま保持期限を適用する。

初期値の取得は同意後のみ。住所権限を除き、追加権限の検証が終わるまでは基本SSO＋直接入力で公開する。全体スキップは初期値もnullにする。通常ログインや言語更新は回答の期限を延長しない。回答は24か月で失効し、完了状態は残す。

更新にはプロフィールrevisionとリクエストUUIDを使い、古い画面の保存と重複送信を防ぐ。回答の削除は履歴を消し、R2の独立した削除記録をバックアップ復元時にも適用する。測定データ・認証・同意の削除とは別の処理とする。

## UIと影響

設定末尾はログイン／新規登録。/loginと/signupにメールとGoogle/Appleを集約し、開発者用は/dev/loginへ移動する。既存の色・カード・入力欄を再利用し、Google初期値の説明はUIに追加しない。ログイン後は同意・成人確認→設問→ホーム。設問完了済みでは繰り返さない。デスクトップはシステムブラウザーと既存の一回限りのハンドオフを維持する。

エクスポートversion=2は新しいUUIDとプロフィール形式。version=1は既存契約を維持し、暗黙に意味を変えない。公開にあたりデスクトップも新しい同意版を理解するビルドへ更新する必要がある。旧版の送信は拒否し、記録はローカルに残る。

## 検証

Workers上での実ライブラリ統合テスト、メールサービスのみモック。本人確認、リセット・セッション失効、拒否・上限、プロフィール再試行・消去・期限・未成年停止を検査する。実メール・SSO・ネイティブ往復・ストア申告は別に検証して公開判断する。
