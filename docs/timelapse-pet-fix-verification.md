# タイムラプスのペット表示・配置操作の修正

確認日: 2026-10-30（JST）。Web / posture-app のみ変更。モバイル、キャラクター契約、録画原本、既存Lottie資産・キーフレームは変更しない。

## 再現と原因

- 設定の旧プレビューは `/figma/timelapse-shima.png` と簡易タイマーを別々に描画しており、現在のウィジェット・動画合成と異なっていた。
- 絵の上から `(-100, -40)px` ドラッグすると、実際の配置移動は `(-11.97, -4.98)px` で止まった。同じ選択枠の空白からなら `(-99.71, -39.80)px` 移動した。画像のネイティブドラッグが配置ジェスチャーを中断していた。
- 現行ウィジェットのSVG表示には白い縞があるが、Canvas合成では消えていた。Lottieの暗黙マット参照がSVGではレイヤー配列の直前、Canvasでは `ind - 1` となる差を確認。例: Goodの縞 `ind:5`、直前のシルエット `ind:7`。Canvasでは別のレイヤーを参照していた。

## 変更

- 読み込み時に既存のマットを `tp` で明示的に関連付ける。シルエット・図形・時刻・イージングはそのまま。旧 `expression-states-v1` も対象にする。
- 設定、再生、書き出しが同じペット描画を利用。現在の本体・縞・吹き出し・178×65のタイマーバー・進捗を共通化。録画時の残り時間とサイクルは継続表示する。
- プレビューは静止フレームを必要時だけ再描画する。ドラッグ中の毎フレームLottie再生は追加しない。
- ネイティブdragを抑止し、ポインターを配置枠で捕捉。本文・タイマー・吹き出しは一組で移動・リサイズする。捕捉解除時にドラッグを終了し、矢印キーの移動・サイズ調整を維持する。
- 枠線を除いた実際の配置領域で移動量を換算する。
