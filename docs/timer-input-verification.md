# タイマー入力とFigma差分の修正（2026-10-27）

## 確定した動作

- 数値入力: 集中1〜120分、休憩1〜60分、1〜12周。編集中は空欄や範囲外を許し、フォーカスを外すと整数・範囲内へ補正する。空欄・0・負数は1、超過は各最大値、小数は整数部分になる。
- スライダー: 時間は5分刻み、最小5分。入力欄で1〜4分を指定した状態からスライダーを操作すると5分以上へ切り替わる。数値欄の矢印キーは1分刻み。
- 1周では休憩0分を即時適用し、休憩入力は読み取り専用、スライダーは無効。2周以上へ戻すと休憩の最小値1分で再開する。
- 保存値の読み込み、保存、新しい測定開始でも同じ正規化を適用。過去の測定記録は変更しない。
- 120の3桁表示を保証するため、桁数に合わせた入力幅と、カードの利用可能な幅に基づく文字サイズを採用。
