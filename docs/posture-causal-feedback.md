# 判定の根拠を部位別の案内につなぐ

2026-11-27。基準コミット `8844131`。

## 要求と範囲

ユーザー要求：肩中心と耳中心を結ぶ線の前後方向を区別してフィードバックにつなぐ。現在測定している値が悪い姿勢の判定原因なら、その原因に合う文言を表示する。

Web・macOS・Windowsの共通測定経路を変更する。既存の判定しきい値・得点・BADまでの待機時間・アニメーションは変更しない。原点は登録姿勢であり、医学的な診断をしない。原本映像・ランドマークや新しい説明情報のサーバー送信は追加しない。

## 実装

- 点数を計算する同じループから、使用された特徴の正規化偏差・信頼度と重みを反映した寄与を返す。説明側で点数式を再実装しない。
- 頭の傾き・過度な顔の回転という独立BAD条件を優先し、総合点によるBADでは現在の寄与が大きい特徴から選ぶ。表示中の原因が引き続き該当する場合は維持する。無関係な大きい観測値を原因として表示しない。
- 肩中心→耳中心のYZ角度に、観測した顔の前後方向による符号を添える。前なら「頭が前に出てるよ！」、後ろなら「頭が後ろに傾いてるよ！」。元の得点用角度の絶対値と片側偏差は維持する。横顔などで前後を確定できない場合は「頭と肩の位置を戻そう！」。
- 横ずれ、耳中心と肩中心の距離、実際の胴体軸、首角度、左右の耳肩距離のバランス、頭肩角度、顔幅加点を説明へ対応させる。方向が裏付けられる既存の顎・肩・顔接近の観測は該当する特徴に限って使う。
- 現在の値が回復してもEMAや状態遷移の待機が残る場合、別の小さな変化を新しい原因として断定しない。観測不能は既存の観測不能案内、未特定は一般案内を維持する。
- ローカルの説明記録をversion 3で区別し、終了コメントには実際の原因だけを集計する。version 2の過去記録は保持し、異なる版を連続時間として合算しない。ウィジェット・録画の発話イベント形式は変更しない。
