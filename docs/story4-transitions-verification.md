2026-10-29。Web PiiiN / Desktop posture-app に反映。今回の範囲はストーリーの静的文字配置と画面間の遷移。既存の未コミット変更は保持し、commit / push は実行していない。

## 参照と変更

- ユーザー提示CSSとFigma `IeFQalpaKriMC94IW7S2Mc` のストーリー4 `4057:5840`、比較対象のストーリー5 `4057:6164` を個別に確認。MCPのプラン上限によりブラウザで選択フレームとPNG書き出しを確認した。
- ストーリー4の7体の配置はすでにCSSと一致していたため維持。文字枠を827pxに明示し、ストーリー4・5にも1〜3と同じSF Pro優先のフォントスタック・標準フォント描画を適用。
- 各場面の文字を180msで退場させ、既存の380msの文字登場へ接続。1〜3は同じLottieインスタンスを維持してポーズを遷移させる。
- 4→5は7体を220msで64px下げながらフェードアウトし、カードレールを48px下から420msで登場。これらは1512×982のデザイン座標。逆方向にも退場が入る。
- ホーム↔ストーリーは180msの退場と320msの登場、12pxの移動で接続。旧画面を短時間保持し、2つのページは同時マウントしない。遷移後に先頭ボタンへフォーカスを戻し、スクロールを先頭へ戻す。
- 連打ガード、タイマーのアンマウント時キャンセル、操作中のinert/aria-disabledを追加。Reduce Motion時は待ち時間なしで切替え、CSSモーションを無効化。
- 泡、ロゴの浮遊・光、初回アナゴ登場、Lottie、怒り、7体の順次登場・呼吸、カードの72秒自動移動・ドラッグ・慣性・ホバーは保持。新規依存、画像・カタログ・保存データ・API変更はない。

- Webの `/app` とデータを変更しない `/dev/work` で、ホーム→ストーリー→1〜5→ホームを実行。
