## カメラと姿勢の処理

PiiiN は、カメラ映像から姿勢を推定し、姿勢の変化を表示するためにカメラを使用します。映像と姿勢の推定処理は利用中のコンピューター上で行います。PiiiN 自体には、カメラ映像を録画して保存したり、開発者のサーバーへ送信したりする機能はありません。マイクの音声は取得しません。

測定にはカメラへのアクセスが必要です。アクセスは Windows のカメラに関するプライバシー設定で管理できます。

## 端末内に保存する情報

獲得したキャラクター、獲得日時、測定識別子、測定時間、良い姿勢の時間・割合・推移、お気に入り、プロフィールに選んだキャラクター、音や表示の設定、初回案内の完了状態を、機能に応じて端末内のアプリ用データ領域に保存します。これらはコレクション表示、測定結果の表示、設定の維持に使用します。

コレクションの獲得情報とそれに付随する測定結果は、ホーム画面の「コレクションをリセット」で削除できます。保存した画像、共有先へ送った情報、OS 等が別途作成したバックアップは、この操作では削除されません。その他の設定はアプリ用データを削除するまで残る場合があります。

## スマートフォンとの連携

利用者がスマートフォンを接続した場合、ローカルネットワーク上で接続先のアドレス、ポート、ペアリングトークン、端末名、接続状態、接続時刻、姿勢の状態と通知時刻を扱います。これらは接続の識別と姿勢状態の通知に使用します。カメラ映像は、この連携の送信対象に含まれません。

連携には HTTP と WebSocket を使用し、通信の暗号化は行っていません。信頼できるローカルネットワークで使用してください。接続情報はアプリの実行中に保持され、アプリを終了すると破棄されます。

## 保存・共有操作

利用者が結果カードの保存・共有を選ぶと、カード画像を端末へ保存したり、クリップボードへコピーしたり、利用者が選んだ共有先へ渡したりします。画像にはカードに表示されるキャラクターや測定結果が含まれる場合があります。共有先による情報の取扱いには、そのサービスのポリシーが適用されます。

## 外部サービスへの通信

姿勢推定に必要なモデルとプログラムを、Google の配信サーバー（storage.googleapis.com）および jsDelivr（cdn.jsdelivr.net）から取得します。その際、接続元 IP アドレスやリクエスト情報が配信先に伝わります。PiiiN は、この取得リクエストにカメラ映像やコレクションの測定結果を添付しません。

Windows版は画面表示に Microsoft Edge WebView2 を使用し、Microsoft Defender SmartScreen を含みます。WebView2 は、Microsoft の説明に従って、信頼性のための診断情報や安全性を確認するための情報を収集し、Microsoft へ送信する場合があります。Windows版の配布・更新には Microsoft Store を使用します。Microsoft による情報の取扱いは、Microsoft のプライバシーに関する声明をご確認ください。

- Microsoft のプライバシーに関する声明：https://privacy.microsoft.com/ja-jp/privacystatement
- WebView2 のデータとプライバシー：https://learn.microsoft.com/ja-jp/microsoft-edge/webview2/concepts/data-privacy
- Google のプライバシーポリシー：https://policies.google.com/privacy?hl=ja
- jsDelivr のプライバシーポリシー：https://www.jsdelivr.com/terms/privacy-policy
