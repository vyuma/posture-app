## 最終再確認と残る差

- 10/28 の再開後、ブラウザ接続は復旧。獲得直後とカードタップ直後の画面離脱で canvas が 1→0 となり、遅延バーストも再出現しないことを確認。グラフ操作では canvas は0、カードタップ時のみ1となること、ホームの既存カード表示では0のままであることを確認した。
- 結果画像を保存し、1442×818 PNG を再表示して確認。操作中のツールチップ・ガイド・フォーカス枠は出力に含まれなかった。
- macOS の再接続はタイムアウトしたため、最後の離脱処理変更後のネイティブ再確認は未実施。以前の macOS 実行確認と区別する。
- Windows 実機、iOS / Android の実機タッチ、OS の Reduce Motion を切り替えた実行は未検証。Reduced Motion の CSS とコンフェティのガードはコードで確認した。
- 未獲得の主見出しは基準幅で -2px の静的補正を追加し、Figma の y205 と一致することを最終ブラウザ実測で確認。
- Figma のオトアナゴ番号は005だが、製品カタログでは006。説明もシマアナゴ用のサンプル文へ上書きせず、各キャラクターの既存カタログ文を表示する。
- グラフ曲線は実データ／検証データを描画するため、Figma の手描き例とは一致しない。
- SF Pro がない OS では既存のフォールバックフォントを使用する。文字幅・ウェイトの見え方を全 OS で一致させたとはしていない。
- ビルドに Lottie の eval、チャンクサイズ等の警告、Rust に未使用のペアリングコードの警告が残る。今回の変更によるエラーはない。
