## 対象と変更

Figma `IeFQalpaKriMC94IW7S2Mc / 4025:3781`（Group 30）の get_design_context とスクリーンショット、ユーザー提供 CSS を参照。数値は 1512×982 の基準画面におけるタイマーバー左上からの相対座標。

時刻だけに付いていた `tabular-nums` が `15:23` を 85.758px に広げ、82px の操作領域を超えていた。Figma の比例数字に合わせると 78.922px となり、末尾とボタンの間隔が 6.836px 広がる。書体・サイズ・太さ・字間は維持。広い時刻だけ横幅を枠内に収める共通テキスト部品を追加した。

Web と desktop の Widget に適用。Web の LP サンプルも同じ部品を使用。既存 Canvas 書き出しは比例数字と maxWidth を既に使用しているため変更なし。キャラクター・吹き出し・既存アニメーション・状態判定には変更なし。モバイルの契約・メタデータ変更なし。
