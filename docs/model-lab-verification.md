# 姿勢モデルラボの統合確認

2026-11-27。PR #37 の `5cd48b7` と main `c2fe7ef` を比較し、最新 main を取り込んで検証した。

## 対象

- Web の `/dev/model` だけを追加する。既存の開発者セッション確認と遅延読み込みを使う。一般アカウントのログインでは開発者権限を付与しない。
- デスクトップのエントリーポイント、既存ウィンドウ、オーバーレイは変更しない。利用者はWeb限定での統合を了承している。
- 計測エンジン、判定しきい値、既存のキャラクター演出は変更しない。映像・ランドマーク・表示履歴を保存・送信する処理は追加しない。

## Standards

初回レビュー3件：小画面でのスクロール不可、終端エラー時のカメラ保持、表示計算の重複に対する回帰検証不足。後者は設計上の判断事項であり、共有エンジンの改変ではなく実エンジンとの比較テストを追加した。

画面内スクロール、表・ログの横スクロール、44pxの操作対象を用意した。難易度選択はキーボードで操作できる押下状態付きボタンとして表現し、フォーカス枠が切れないようにした。新しい回帰テストはWeb CIから個別プロセスで実行する。

## Spec

初回レビュー3件：エラー・初期化取消時の資源管理、欠測時にEMAを生スコアへ代入する問題、x₆の片側偏差と画面の式の不一致。

エラー・画面終了で共通の後始末を実行し、非同期初期化の各段階で取消を確認する。欠測のrawはnullを保持してグラフを途切れさせ、EMAとの時間位置を維持する。x₆の `max(0, x₆ − median)` を明記した。再登録は次の映像フレームを待たず基準表示を初期化する。

## 検証

- `scripts/model-lab.test.tsx`：修正前は7件中5件が失敗、修正後は7件・62 assertions成功。モデル初期化失敗、推論失敗、WASM/モデル初期化中の終了、欠測グラフ、再登録、実エンジンとのraw/EMA一致を確認。
- Web・デスクトップのビルド成功。デスクトップの生成物にModelLabチャンクが含まれないことを確認。既存の開発者アクセス回帰も1件・9 assertions成功。既存の大きいバンドルに関する警告は残る。
- 合成ランドマークを使い、実際のコンポーネントと姿勢エンジンでGOOD→WARNING→BADをブラウザー実行。カメラ・MediaPipeの取得部分だけをテスト用に差し替えた。実映像・実カメラの精度検証とは区別する。
- 1512×982、1024×640、390×844でルートの横方向のはみ出しは0px。390×844の最終確認は内部スクロール位置1299px、最後の判定表示の下端803pxで到達可能。操作ボタンの高さは44px。
- Spaceキーで難易度を変更でき、押下状態とフォーカス枠が更新されることを確認。合成推論エラー後はカメラ停止・モデルcloseがそれぞれ1回。
- 既存の警告アニメーションとReduce Motion用CSSは保持。OSのReduce Motion設定切替・実タッチ操作は未実施。
- Impeccableの機械検査は指摘0件。これは全画面のアクセシビリティ認証や、実カメラの品質保証を意味しない。
- 証跡：ローカル作業領域 `Documents/piiin/output/pr37-model-lab/bad-1512.jpg`、`bad-390-bottom.jpg`。合成データ用ハーネスは製品・コミットに含めない。

Standards・Specの再レビューでは、修正範囲に残る確実なブロッカーはなかった。開発者ログイン後は `/dev/model` を手動で開く（既存の `/dev/anago` と同じ）。実カメラのBAD操作、デスクトップへのラボ追加、TestFlight配布は今回の確認に含まない。
