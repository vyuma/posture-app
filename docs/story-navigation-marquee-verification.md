# ストーリーの矢印位置とカード連続移動（2026-10-27）

## 修正内容

縦長画面ではストーリー4だけが中央の矢印配置、他の場面は下端配置だった。ストーリー1〜3・5も中央の同じ高さに揃えた。ストーリー4の接地・位置・モーションは維持する。

ストーリー5は縦長/狭幅用CSSの `animation: none` と複製カードの非表示を除去し、旧実装と同じ72秒・linear・開始遅延0.9秒の連続移動に戻した。8枚×4組を表示し、1組の幅だけ移動して繰り返す。キーボードフォーカス、ホバー、タッチ中の一時停止とReduce Motion時の静止表示を保持する。ポインタークリック後のフォーカスだけで止まり続けないよう `focus-visible` に変更した。

縦長画面のカード列は矢印より下に配置。320×568ではカード全体を見るため88pxの縦スクロールを許可し、スクロール後も矢印とカードを操作できる。

- 853×893でストーリー1〜5を順に確認。全矢印の中心Y446.5、上端418.5、56×56px。左右余白16px。ストーリー4の画像下端と画面下端の差0px。
