## 2026-10-29: 획득일시의 왼쪽 기준선 수정

- 최신 사용자 지시에 따라 컬렉션 상세의 획득일시를 `集中した時間`과 같은 왼쪽 시작점에 정렬했다. 이전 Figma CSS의 고정 너비·오른쪽 정렬보다 이 지시를 우선한다.
- 날짜와 통계가 같은 `--metrics-left-inset`을 사용한다. 540px 이하에서는 컬렉션 통계의 양끝 배치를 사용하며, 긴 집중시간 값에도 제목 시작점이 고정된다.
- 획득 화면과 저장 PNG는 기존 날짜 오른쪽 정렬 및 통계 배치를 유지한다. 기존 모션·서체·색상·상하 간격은 변경하지 않았다.
- 수정 전 1512px에서 날짜 글자 시작점이 제목보다 13.18px 오른쪽, 390px에서 26.70px 왼쪽에 있었다.
- 수정 후 Chrome DOM Range로 글자 시작점을 측정: 1512×982, 720×512, 390×844 모두 차이 0px. 실제 컬렉션 팝업(140분)과 타임랩스 버튼을 포함한 카드(0분)를 확인했으며 가로 오버플로 없음.
- macOS Tauri 실제 앱의 1200×752 및 720×512 콘텐츠 영역에서 동일한 왼쪽 정렬을 스크린샷으로 확인했다. 네이티브의 DOM 수치는 측정하지 않았다.
- 390px 팝업에서 저장을 실행하고 다운로드 PNG의 기존 날짜 오른쪽 정렬과 통계 배치를 확인했다.
