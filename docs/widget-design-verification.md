## 動作

優先度は一時停止 → 休憩 → 悪い姿勢 → 良い姿勢。休憩は曲がった睡眠姿勢、一時停止は直立した閉じ目の姿勢を使う。

既存 good / bad / rest の Lottie レイヤーとキーフレームはそのまま保存。既存の upright paused ポーズを使い、不足していた pause の相互遷移だけを追加した。再生中に状態が切り替わった場合は現在の遷移を終えて最新状態へ進む。Lottie の segment 再生後に全体フレームへ戻す処理も実行確認済み。

悪い姿勢が続くと既存と同じ 5 秒で拡大し、0.68 秒周期の揺れを継続する。タイマーバーは拡大しない。高さが不足する場合はキャラクターの拡大率を抑える。姿勢復帰後はモーフを見せてからネイティブウィンドウを縮小する。Reduce Motion では拡大・揺れ・モーフを停止する。

新規タイムラプスは widget-states-v2 を記録し、映像内のペットにも同じ表示を使用。既存 v1 動画は従来のフレーム対応を維持する。映像内では操作ボタンの代わりに記録したサイクルを表示する。

## 未検証・制約

- macOS のドラッグは自動操作から実移動を確認できなかった。既存のネイティブドラッグ処理は維持しているが、手動での移動確認は残る。
- Windows 実機、異なる DPI の複数モニター、OS の Reduce Motion 切り替えは実機未検証。縮小上限と Reduce Motion 分岐は単体テストで確認。
- IAB と Chrome の合成ファイル書き出し検証は、入力動画デコーダーで `This video track cannot be decoded in this environment` となり失敗。カメラのみでも合成前に失敗するため、新ウィジェットを含む書き出し成功は確認できていない。実際の動画再生・画面合成の成功と区別する。
