# Store 紹介文の原稿

## 説明

良い姿勢を続けて、ピンアナゴを集めよう。

PiiiN は、パソコンのカメラを使って姿勢の変化を推定し、キャラクターと一緒に毎日のパソコン作業を楽しむデスクトップアプリです。

自分の良い姿勢を登録してから測定を始めると、測定中の状態を確認できます。デスクトップ上のキャラクター表示や測定結果を通じて、姿勢を意識するきっかけをつくります。獲得したピンアナゴはコレクションから見返せます。

主な機能
・良い姿勢の登録と、カメラを使った姿勢の測定
・デスクトップ上へのキャラクター表示
・測定結果の表示とピンアナゴのコレクション
・お気に入りとプロフィール用キャラクターの選択
・同じローカルネットワーク上のスマートフォンとの連携

姿勢の測定にはカメラが必要です。姿勢推定はパソコン上で行い、PiiiN 自体がカメラ映像を開発者のサーバーへ送信することはありません。推定用モデル等の取得にはインターネット接続が必要です。

本アプリは医療機器ではなく、診断や治療を目的としたものではありません。

## 審査担当者向けメモの案

このパッケージは既存の Tauri デスクトップアプリを MSIX 化したものです。runFullTrust は Windows デスクトッププロセスの起動、カメラを利用する WebView2 のホスト、デスクトップオーバーレイ、およびローカルネットワーク上のスマートフォン連携のために使用します。

ログインは不要です。初回案内を進めてホームを開き、良い姿勢の登録と測定を確認できます。カメラは必要ですが、マイクは使用しません。スマートフォンとの連携には同じ LAN と QR に含まれるペアリング情報を使用します。

WebView2 Fixed Version Runtime を同梱し、Windows 版には独自の Tauri Updater を組み込んでいません。更新は Microsoft Store の配信を利用します。

## スクリーンショットの未完了事項

Windows 上で実際のパッケージを起動し、ホーム・測定・コレクションを撮影する。Figma、macOS の画面、ブラウザーの画面を Windows アプリの実機画像として提出しない。カメラ映像やペアリング QR・トークンなどを公開用の画像に含めない。
